# Phase V — Consequential-LCA Kill Test

## Purpose

Phase V deliberately attacks SCT with the strongest causal comparator rather than a weak static baseline.

Consequential LCA is designed to include activities that change because of a decision or a change in demand. Dynamic LCA can also include time-dependent inventories. Therefore SCT must not claim that merely propagating future environmental consequences is unique.

## Kill-test result

If a fully informed consequential/dynamic model observes the same complete future consequence trajectory as SCT and uses the same aggregation rule, its cumulative score is identical to SCT by construction.

This means the paper must **not** claim:

- SCT universally outperforms consequential LCA;
- causal propagation itself is new;
- time-dependent lifecycle accounting itself is new.

## Surviving novelty boundary

The defensible contribution is narrower:

1. define a declared observation interface;
2. prove when that interface is insufficient to identify future sustainability closure;
3. construct indistinguishable systems with different future closures;
4. quantify which omitted future-response mechanisms change the sustainability verdict;
5. show that observation refinement restores identifiability in the tested construction.

This turns SCT from “another lifecycle score” into an **information-sufficiency and closure-completeness theory for sustainability assessment**.

## Interpretation

A fully informed consequential model is not a loser in the benchmark; it is the limiting comparator. SCT's formal value is in diagnosing when the information available to an assessor is insufficient to reproduce that limiting assessment.
